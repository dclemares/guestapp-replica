02 · Access

Door code

The keypad is on the right of the front door. Your personal code unlocks it from your arrival time until check-out.

  1. We show your code in the app as soon as you finish check-in.
  2. Type the code on the keypad and push the door.
  3. If the keypad doesn’t respond, press # twice and enter the code again.
  4. Please don’t share your code with anyone.
The spare key is in the key box to the left of the gate, in case you ever need it.
